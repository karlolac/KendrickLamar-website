# 🎤 Kendrick Lamar – Fan Page Website

A clean, responsive web application dedicated to Kendrick Lamar, built to showcase the artist's biography, music discography, image gallery, and interactive contact features.

---

## ✨ Features

* **Homepage / Biography:** Intro section featuring artist profile, background, and career overview.
* **Photo Gallery:** Showcase of iconic images and visual aesthetics.
* **Discography / Albums:** Dedicated section highlighting notable albums and tracks.
* **Contact & Socials:** User interactive contact form and social media integration.
* **Responsive Layout:** Optimized navigation bar and multi-page/single-page layout flow for seamless browsing.

---

## 🛠 Tech Stack

* **Frontend:** HTML5, CSS3, JavaScript
* **Styling:** Custom CSS, Flexbox/Grid for layout structuring
